# Contributing

Thank you for helping. Before a pull request can merge you must agree to the [Contributor Agreement](CLA.md) once. It assigns your contribution to the project owner so the project can change its licence later; it does not stop you from using your own code.

- Only submit work you wrote, or material whose licence you name in the pull request.
- Do not paste code from other projects without saying where it came from.
- Do not include personal data or real case material in examples or tests.

Maintainer notes: never merge outside code before the CLA is signed. Keep the bot's record of each signature.
